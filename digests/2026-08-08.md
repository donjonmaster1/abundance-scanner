### To declare this Council’s intention to amend the Zoning Map by rezoning certain properties from Title 33 Zoning Code district designations to new Title 34 2024 Zoning Code district designations, and…
- **Jurisdiction:** Columbus, OH
- **Source:** [Legistar (municipal)](https://columbus.legistar.com/LegislationDetail.aspx?ID=129785&GUID=770C0057-B249-4E70-8E12-A01E696FF36F)
- **Status:** Passed (as of 2026-08-07)
- **Summary:** Columbus City Council passed legislation declaring its intent to rezone certain properties from the old Title 33 zoning code to the new Title 34 2024 Zoning Code, part of the city's broader zoning reform effort. The measure was passed as an emergency, allowing implementation to proceed without the standard waiting period. This is a procedural but necessary step toward applying Columbus's modernized zoning framework, which is designed to enable more housing development citywide.
- **Why it matters:** A modest but meaningful administrative step that helps operationalize Columbus's zoning code modernization, which underpins the city's broader push to increase housing supply.
